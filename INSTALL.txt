Battery Alert / 电池提醒

Requires macOS 13 Ventura or later. Supports Apple silicon and Intel Macs.
需要 macOS 13 Ventura 或更新版本，支持 Apple 芯片与 Intel Mac。

1. Drag Battery Alert.app to Applications, then open it from Applications.
   把 Battery Alert.app 拖到 Applications（应用程序），再从应用程序中打开。
2. Click the battery outline icon in the menu bar.
   点击菜单栏中的电池轮廓图标。
3. Click Allow notifications. If notifications were previously denied, enable
   Battery Alert in System Settings > Notifications and select Banners.
   点击「允许通知」。如曾拒绝权限，请到系统设置 → 通知 → 电池提醒中开启，选择「横幅」。
4. Send a test notification, choose your threshold (15% by default), and optionally
   enable Launch at login. Focus and system notification settings can suppress alerts.
   发送测试通知，设置提醒电量（默认 15%），按需开启「登录时启动」。专注模式及系统通知设置可能隐藏提醒。

This build is ad-hoc signed and has NOT been notarized by Apple.
If macOS blocks it, attempt to open it, then go to System Settings > Privacy &
Security and use Open Anyway for Battery Alert if that option is offered.
No need to disable Gatekeeper or run commands that remove security protections.
此版本使用临时签名，尚未经过 Apple 公证。如被系统拦截，请先尝试打开，再到
系统设置 → 隐私与安全性中查看并使用此应用对应的「仍要打开」（如提供）。
无需关闭系统安全防护。

The app only runs while open. Quit from the menu bar to stop monitoring.
To uninstall, turn off Launch at login, quit, then move the app to Trash.
程序运行期间才会监测电量。从菜单栏退出即可停止。
卸载前关闭「登录时启动」，退出程序，再将应用移到废纸篓。

All battery data and preferences stay on your Mac. No network requests,
accounts, analytics, or battery-management changes. This app provides an
additional notification; it does not change Apple's built-in 10% warning.
电池数据与偏好设置只保存在本机。无联网、账号、统计或电池管理修改。
此工具额外发送低电量通知，不修改苹果自带的 10% 提醒。
