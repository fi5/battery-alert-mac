Battery Alert · 电池提醒

原生 macOS 菜单栏工具，默认在电量降至 15% 或以下时发送系统通知。

- 可调整 5%–50% 提醒阈值；可开关提示音。
- 电池图标、原生横幅通知及通知测试。
- 登录时启动、中文与英文界面。
- 支持隐藏菜单栏图标，从应用程序重新打开设置。
- 设置面板略微缩窄并收紧间距。
- 支持 macOS 13+、Apple 芯片及 Intel。
- 无联网、无账号、无统计。

下载 `.dmg`，将 App 拖入 Applications，打开后允许通知。

**当前构建使用临时签名，尚未经过 Apple 公证。** 首次打开方法、通知设置及卸载说明请见 README。专注模式和系统通知设置可能隐藏提醒；Mac 睡眠或 App 退出时不会通知。

The build is ad-hoc signed, not notarized. Requires macOS 13 or later. Universal binary for Apple silicon and Intel. See the README for installation and notification setup. `SHA256SUMS.txt` contains artifact checksums.
